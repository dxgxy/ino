# 当前功能说明

## 1. 用户主流程

### 1.1 创建学习内容

1. 首次打开进入空的 List 工作区。
2. 点击“新建 List”创建空组，或打开“词典与词书资料库”。
3. 词书支持分页浏览、关键词过滤、多选加入已有 List、创建新 List，以及按起点、数量和每组 10–30 词自动生成多个 List。
4. 生成前排除已经安排到其他 List 的词，生成后仍由用户决定是否保留。

### 1.2 学习卡片

List 主区显示卡片行，右侧显示当前详情。点击卡片行切换详情；点击详情卡片空白处切换下一张；点击发音按钮只播放当前单词。删除卡片只影响当前 List，不删除词库内容。

WordCard 当前字段：

- `id`：稳定卡片 ID。
- `kind`：`word`、`sentence` 或 `custom`，后两类为预留扩展。
- `content`、`translation`、`definition`：词面和释义。
- `phonetic`、`audioUrl`、`example`、`exchange`：发音、例句和词形信息。
- `source`、`sourceUrl`、`tags`、`updatedAt`：来源、标签和版本信息。

### 1.3 四种复习方案

复习只针对当前 List：

1. **隐藏含义**：显示英文和音标，用户判断是否认识。
2. **只听发音**：播放或重播英文发音，用户判断是否认识。
3. **含义拼写**：显示中文含义，用户填写英文；拼写规范化后比较。
4. **含义识词**：显示中文含义，用户判断是否想出对应英文。

点击作答后立即尝试播放发音并展示完整卡片，之后选择“符合预期”或“不符合预期”。没有完成最终确认，不写入成功记录。拼写方案必须拼写正确才可能增加今日巩固度；发音失败不会阻止离线复习。

### 1.4 记忆进度

界面名称和含义：

- **今日巩固度**：当前日期内的复习进度；换日时从衰减后的长期记忆度重新开始。
- **长期记忆度**：跨天的记忆积累；长期不复习会按衰减规则下降。

每条记录用 `(listId, cardId)` 隔离，因此同一个词在不同 List 中拥有不同进度。默认参数为：长期记忆度初值 0、今日巩固度达标值 3、每词每日尝试上限 20、长期记忆度达到 7 后归档。所有参数可按 List 修改。

今日巩固度只在成功且符合预期时增加；不认识、确认不符合预期、拼写错误都不增加。一个日期内达标后，长期记忆度最多增加一次。达到归档阈值的卡片移动到当前 List 的归档区，可恢复并清零进度。

算法边界和公开来源见 `REVIEW_DESIGN.md`。本项目采用 FSRS-4.5 遗忘曲线的稳定度思想，不声称实现完整 FSRS，也不把默认阈值当作医学或心理学结论。

## 2. 账号与数据边界

网页使用同源 HttpOnly Cookie；Electron 使用主进程内存令牌，令牌不写入渲染进程或磁盘。服务端 SQLite 只保存用户资料、scrypt 密码哈希和有限会话。学习数据使用本地存储，按访客/账号分区。

远程账号服务不可用时：

- 本地词库、List、发音和复习仍可用。
- 缓存昵称只用于界面展示，不授予服务端权限。
- 账号登录、注册、修改资料需要后端恢复后重试。

## 3. 已实现接口与扩展接口

当前服务：

- `libraryService`：异步加载本地词库和词书元数据。
- `studyListService`：创建、去重和自动分组 List。
- `accountService`：账号 API 客户端。
- `speak`：音频优先、系统语音降级。
- `review.ts`：复习方案、记录、跨日重置、衰减和归档判断。

预留接口：`ReviewService`、`SearchService`、`ImportService`、`SyncService`、`CommunityService`、`BillingService`。服务端当前不接收学习明细，后续同步必须增加显式开关、冲突策略和数据导出/删除路径。

## Android 首页

首页是 Android 专用仪表盘，不改变桌面端 List 工作区：

- 头像/等级区显示账号验证状态或访客/离线状态。
- 搜索框调用本地词库和功能模块注册表；不联网也能查询英文、中文释义和功能入口。
- List 卡片按今日达标数、待复习数和长期记忆度衰减情况显示。
- 今日简报使用当天记录字段统计；旧版本没有当天字段时显示 0，不伪造历史。
- 未来七天仅为“当前不继续复习”的排程预览，不把预测当成保证任务。
- 底部导航提供首页、List、设置和扩展；扩展入口当前显示预留模块说明。

## Android UI 重组

Android 首页使用独立的移动端信息架构：顶端身份区、离线搜索、今日任务主卡、List 进度、今日简报、艾宾浩斯规划和底部导航。桌面端的侧栏 List 继续保留在 List 工作区，首页不显示它。
